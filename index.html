Frequently Asked Questions

Everything you need to know before getting started with SIDMax.

SIDMax is compatible with AutoCAD 2018 and above, including AutoCAD LT (limited commands). It is also fully compatible with RebarCAD 2019+. We recommend using AutoCAD 2021 or later for the best experience with all 89+ commands.
Yes — SIDMax was built with RebarCAD in mind. The layer naming conventions, BBS export format, and rebar callout standards all align with RebarCAD workflows out of the box. No manual configuration required.
Installation takes under 2 minutes. Download the installer package, run the setup wizard, and SIDMax will automatically load into AutoCAD at startup via the LISP autoload mechanism. Detailed installation guides are available in our Help Center.
Based on feedback from our users, detailers save an average of 10–15% of their total drafting time per project. For large structural projects (200+ drawings), this can translate to 2–5 full working days saved per project lifecycle.
