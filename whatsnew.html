v2.4.0
Major
August 2026
This release introduces the new BBS auto-export pipeline, collapsible command categories in the dashboard, and multiple layer management improvements that reduce layer conflicts to zero.
NEW FEATURES
  • BBS auto-export pipeline — generate Bar Bending Schedules from drawing data in one command SIDmax_BBS_Export
  • Smart rebar array command with automatic stirrup spacing SIDmax_RebarArray
  • Continuous elevation tag placement with auto-increment SIDmax_ElevTag
  • Layer dictionary auto-generation — creates all SIDMax standard layers in one click SIDmax_LayerDict
IMPROVEMENTS
  • Offset calculation engine is now 3x faster on large drawings with 1000+ entities
  • Improved unit conversion accuracy for inch-to-mm rebar diameter lookups
  • Command aliases now case-insensitive for faster terminal entry
BUG FIXES
  • Fixed crash when BBS table exceeded 200 rows in AutoCAD 2022
  • Fixed layer conflict when running multiple rebar commands in quick succession

v2.0.0
Major

NEW FEATURES
  • 89+ new automation commands across 12 categories
  • New modular LISP architecture for easier future extensibility
  • Official SIDMax Dashboard website with command directory and roadmap
